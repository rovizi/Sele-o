# API DO LIVE GOL - SEÇÃO SELEÇÃO (BRASIL E CABO VERDE)
# Descrição:
# Esta API gerencia e fornece o calendário oficial, placares reais e
# o status em tempo real das partidas da Seleção Brasileira e de Cabo Verde
# para a aba "Seleção" do site Live Goal.
#
# Funcionalidades:
# - Retorna o histórico e resultados reais (como o jogo recente do Brasil
#   contra a Austrália e o confronto de Cabo Verde).
# - Automação de status: muda automaticamente para "Ao Vivo" quando
#   faltarem 10 minutos para o início da partida.
# - Integração CORS ativada para consumo direto pelo front-end.
